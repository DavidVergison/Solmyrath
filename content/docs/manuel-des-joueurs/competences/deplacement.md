## Description

Déplacement couvre toute forme de mouvement athlétique : sprinter, franchir un obstacle, escalader un mur, nager en eaux vives, garder l'équilibre sur une surface instable. En combat, c'est aussi la compétence utilisée pour l'esquive.

## Exemples d'utilisation

- Escalader un mur de forteresse.
- Sauter par-dessus un fossé.
- Traverser une rivière à la nage.
- Courir sur les toits d'une ville.

## Prouesses

| Prouesse | Effet |
|----------|-------|
| Zone supplémentaire | Se déplace d'une zone supplémentaire |
| Action supplémentaire | Peut effectuer une action rapide de plus ce round |
| Atterrissage parfait | Termine le mouvement en position avantageuse (couvert, hauteur, flanc) |
| Partager | Donne un succès à un autre PJ dans la même situation |

{{< hint info >}}
En combat, Déplacement est aussi la compétence d'**esquive**. Voir les règles de combat pour le détail.
{{< /hint >}}
